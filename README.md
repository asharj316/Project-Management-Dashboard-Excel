# Project-Management-Dashboard-Excel
Interactive Excel Project Management Dashboard for tracking task progress, project timelines, team assignments, and budget vs. actual spending using Gantt charts, KPIs, and slicers.

# Overview
The dashboard provides a consolidated view of multiple projects, helping users track task completion, monitor project schedules, and compare budgeted costs with actual spending.

## Key Features

* **Project Tracking:** Monitor multiple projects and their associated tasks.
* **Task Progress Monitoring:** Track task completion percentages and remaining work.
* **Gantt Chart:** Visualize task schedules, durations, and project timelines.
* **Budget vs. Actual:** Compare planned budgets with actual project expenses.
* **Team Management:** Filter project information by assigned managers.
* **Interactive Slicers:** Analyze individual projects and team members.
* **KPI Visualizations:** Monitor overall task progress and project status.

## Tools & Techniques

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Slicers
* Conditional Formatting
* Excel Formulas
* Gantt Chart Visualization

## Dashboard Preview

The dashboard includes project and manager filters, task-level details, progress indicators, project timelines, and budget analysis.

## Project Purpose

This project demonstrates how Microsoft Excel can be used to organize project data, monitor performance, and present project information through an interactive dashboard.
